# ArchiveLens — Design System

**Sahara — Warm Minimalism**

North Star: **"Sun-Baked Simplicity"**

Luxurious warmth combined with disciplined minimalism.

---

## Colors

| Role | Hex | Usage |
|------|-----|-------|
| Primary | `#c2652a` | Burnt sienna — primary CTAs, focus states, key interactive elements |
| Background | `#faf5ee` | Warm linen — primary surface. Never cold white |
| Tertiary | `#8c3c3c` | Dusty rose — used sparingly, accents only |
| Text | `#3a302a` | Warm near-black body |
| Text muted | `#6b5e52` | Secondary/metadata text |
| Border | `#d8d0c8` | Warm gray, ~60% opacity |
| Card surface | `#fffdf9` | Warm white, slightly lighter than background |

All neutrals carry warm undertones. No cold blue/gray.

---

## Typography

- **Headings / Hero / Editorial:** EB Garamond (serif)
- **Body / UI / Nav / Buttons / Labels / Metadata:** Manrope (sans)

Serif-sans combination creates refined editorial appearance.

Scale (editorial):
- Hero: 56–72px
- Page title: 36–48px
- Section heading: 28–32px
- Body: 16–18px
- Metadata: 13–14px

---

## Elevation

Extremely subtle shadows only:

`0 2px 16px rgba(58, 48, 42, 0.04)`

Prefer background tinting over obvious elevation.

---

## Components

### Primary button
- Background: burnt sienna `#c2652a`
- Text: light `#fffdf9`
- Radius: 8px
- Hover: darken slightly + subtle lift

### Secondary button
- Transparent/warm background
- Warm border
- Radius: 8px

### Links
- Underline on hover only

### Cards
- Warm white surface
- 28–32px padding
- Minimal borders
- Very subtle elevation

### Inputs
- White/warm-white background
- Warm gray border
- Burnt sienna focus state

---

## Core Design Rules

- **Whitespace is the primary design tool.** Add whitespace, not more UI.
- Content must feel: Curated, Calm, Editorial, Premium, Uncluttered.
- Avoid: excessive cards, badges, gradients, neon colors, cold blue/gray UI,
  generic SaaS styling, excessive rounded containers, heavy shadows, clutter.
